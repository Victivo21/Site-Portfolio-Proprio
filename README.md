# Site-Portfolio-Proprio

## Trabalho Desenvolvimento Front-End 
Site de portifolio Prorpio com cinco páginas estaticas em HTML5 semantico, CSS e Javascript 

# Estrutura do Site 
1. 'index.html' -- Pagina inicial e Conteudo Sobre Mim 
2. 'curriculo.html' -- Pagina de curriculo, mostrando minha carreira ate agora e algumas de minhas habilidade e formações 
3. 'formulario.html' -- Pagina de formulario para contado 
4. 'multimidia.html' -- Pagina com um video em mp4, um audio em mp3, um video do youtube e uma `iframe` do Google Maps 
5. 'grafico.html' -- Pagina de visualização de um Grafico CANVA e um Grafico SVG
